# Half life and activity

## Activity
- number of unstable atoms in the source that decay per second
- measured in Becquerel's (Bq)
## Count rate
- ***observed*** number of emitted [[TypesOfRadiation|particles]]
- often measured using Geiger counter

## Half life
- avg. time it takes for the number of nuclei of an isotope in a sample to halve
- i.e. time for the activity/count rate to halve
- Average because radioactive decay is random [[NuclearDecay#^343142|NuclearDecay]]
