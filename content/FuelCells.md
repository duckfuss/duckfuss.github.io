# Fuel Cells

## How they work (__VERY__ oversimplified)
- Cognito version (___DIFFERENT TO KERBOODLE___)![[draw_FuelCell.svg|draw_FuelCell.svg]]
- Hydrogen is oxidised, setting up a potential difference across the cell, producing water
- at anode (-ve (opposite to electrolysis where anode +ve))
	- $2H_{2}\rightarrow4H^++4e^-$
- at cathode
	- $O_{2}+4H^++4e^-\rightarrow2H_{2}O$
- Overall:
	- $O_{2}+2H_{2}\rightarrow2H_{2}O$ 

## Advantages vs Disadvantages
| Advantages                                         | Disadvantages                                  |
| -------------------------------------------------- | ---------------------------------------------- |
| Only requires H and $O_{2}$                        | H is a gas -> takes more space to store        |
| no pollutants as waste                             | H is explosive when mixed with air             |
| fuel cells = simple -> last longer                 | Requires energy to make H (from fossil fuels?) |
| don't need to be electrically charged              |                                                |
| Can be range of different sizes for different uses |                                                |
